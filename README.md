🎯 Objetivo do Projeto

O objetivo principal desta aplicação web é consolidar e demonstrar na prática os conceitos fundamentais de Interação Humano-Computador (IHM), focando em:

Usabilidade e clareza visual.

Arquitetura de informação e redução da carga cognitiva.

Design inclusivo e acessibilidade web (WCAG).

Layouts responsivos e adaptáveis a múltiplos dispositivos.

🛠️ Tecnologias Utilizadas

HTML5 Semântico: Estruturação clara de conteúdo (<header>, <nav>, <main>, <section>, <article>, <footer>).

CSS3 moderno: Estilização, variáveis CSS, CSS Grid e Flexbox para layouts responsivos.

Media Queries: Garantia de adaptabilidade fluida para smartphones, tablets e desktops.

♿ Princípios de IHM e Acessibilidade Aplicados

Semântica HTML5: Estrutura clara que facilita a navegação por tecnologias assistivas (leitores de ecrã).

Contraste de Cores: Rácio de contraste otimizado entre texto e plano de fundo para evitar fadiga visual e atender utilizadores com baixa visão.

Textos Alternativos (alt): Todas as imagens de projetos possuem descrições detalhadas para leitores de ecrã.

Navegação por Teclado: Suporte completo à navegação por Tab, exibindo o indicador visual de foco (outline) em botões e links.

Responsividade (CSS Grid): Reorganização automática dos elementos para preservar a usabilidade tanto em ecrãs móveis quanto em desktops.

🚀 Como Executar o Projeto Localmente

Clone o repositório ou faça o download dos arquivos:

git clone https://github.com/seu-usuario/portfolio-ihm.git


Acesse a pasta do projeto:

cd portfolio-ihm


Abra o arquivo index.html em qualquer navegador web de sua preferência (Firefox, Chrome, Edge, etc.).
